# 局部排布与习惯观察：设计说明

## 目标与取舍

本次对应用户反馈：全自动自适应实验版过于克制，整理前后缺少明确变化；希望另有一个能长期运行的辅助程序记录调节习惯，但这些习惯只是推断意图的参考，不是标准答案。

上一实验版只有很小的局部整理半径与全屏模板候选，中间缺少完整的局部方案；移动、缩放、注意力稳定等多项惩罚叠加，使不动经常占优。新版本保留原有能力，但将产品 Smart 路径改为 `IntentLayoutPlanner`。`HumanCenteredSmartPlanner` 与旧学习器保留供旧测试／实验对照使用，不再从主程序调用其在线学习路径。

## 排布器

按显示器分组，再按窗口投影重叠／邻近距离找连通的工作组。每组比较原状、上一版的局部求解结果、保留尺寸的行／列／多行排布，以及尺寸差距很小时的齐高方案。候选围绕当前组的中心，而不是围绕整个屏幕；只在贴近屏幕边缘时选择边缘锚点。

评分关注重叠、对齐、间距和粗略空间顺序，移动与缩放仍有成本，但不再对“所有改变”另加整套学习惩罚。前台窗口的移动成本稍高。温和／均衡／积极影响移动意愿、预算与改进门槛。一次明确整理可以处理深一些的重叠，松手后的随手辅助仍是另一条小范围路径。

候选必须满足尺寸可用性、固定尺寸窗口约束、工作区边界和有界移动／缩放；不能增加组内重叠，也不能侵入已排好的其他工作组。不能因为参考数据而绕过这些检查。无法实现的候选丢弃，出屏救回是单独的正确性约束。

撤销保留最近一次有实际移动的计划。恢复前核对窗口句柄、进程、显示器、工作区和当前矩形；不覆盖后续手动修改。Windows 自身钳制了目标尺寸时也可能跳过撤销，不会假装已成功恢复。

## 记录器的数据生命周期

1. 真实 move/size 开始：在内存中保留起始矩形与窗口身份。
2. 结束：保留原始落点、工作区、DPI、时长及最多 24 个邻居矩形，排队等待确认；没有变化的操作跳过。
3. 两秒观察窗口：新操作使前一落点成为 `superseded`；NeatWin 的移动标记使它成为 `automation`；跨屏、关闭、不可管理和再次改变分别标记。
4. 原始观察按 JSONL 写入。非稳定观察可以用于后来分析，但不会进入弱参考提取。没有动作时不制造“满意样本”。
5. 稳定观察中，只有明确完成接近的间距或边对齐关系，才产生一个小的参考样本。

原始字段：`Time`、`Session`、`WindowId`、`Start`、`End`、`StartWorkArea`、`WorkArea`、`Dpi`、`DurationMilliseconds`、`Neighbors`、`Outcome`。窗口编号只在当前记录器会话内有意义。几何不包括内容、标题或应用身份。

摘要字段：格式版本，以及 `Time`、屏幕宽高比类别、DIP 间距、横向关系标记。分“竖屏／普通／超宽”背景，不把绝对像素偏好直接跨 DPI 复制。它不是每个应用的个性化配置，也不是布局模板。

只使用最近 30 天、最多 128 个摘要样本；同类背景 30 秒内重复观察去重。至少 6 个样本、覆盖 3 个不同的五分钟桶后才生效。中位数减少异常值影响，离散度抑制不一致参考，14 天半衰期降低过时影响。间距融合上限 25%，结果限制为 6–14 DIP；方向偏好仅有很小的评分影响。

这不是监督学习“正确摆放”，也不推断用户没动就是认可。未来可以从导出的原始观察中研究方向、连续操作与上下文，但不应直接拿 End 矩形训练复刻器。

## 运行、安全与失败处理

独立 WinForms 托盘进程，进程级单实例。使用 out-of-context WinEvent 和消息循环，回调委托保持引用；不安装键盘钩子或持续采样鼠标轨迹。记录器不会调用窗口移动路径。回调只做捕获和暂存；文件写入在计时器确认后执行。

活动状态、等待队列、会话窗口索引、原始日志、参考样本均有上限。文件按大小滚动，运行期间约每小时清理过期日志，写入后也清理。进程崩溃或立即退出可能丢失尚未确认的两秒观察；不为最后一条记录拦截关机或强制同步系统窗口。

参考更新使用临时文件、落盘后替换，主程序共享读取并限制输入大小。损坏、未知版本、过大、过期、未来时间或非有限数据回退到默认值。主程序与记录器分别管理主设置和记录文件，不互相覆盖设置。

NeatWin 应用目标前，在窗口上设置短期自动化标记；记录器在开始、结束和等待确认时检查。标记不含内容、不写文件，随窗口销毁移除。第三方自动化未必带标记，所以记录依然只是有噪声的观察。

开机启动需要主动勾选，只写当前用户 Run 项；无服务、驱动、管理员安装或计划任务。暂停立即丢弃待确认观察。退出释放钩子、计时器和托盘图标。记录写入或权限失败在面板显示，不阻断用户拖动。导出是用户选择的本地 ZIP，不会上传。

## Windows 手动验收（不能由纯几何测试代替）

- 普通屏上两到三个窗口间隔约 80–150 px、顶部错开：点整理，应有明显对齐与收拢；再点一次不应持续漂移。
- 5120×1440 超宽屏上留出较大空白：局部工作组应仍在附近，不拉满整个屏幕；左右顺序不颠倒。
- 两窗口较深重叠：明确整理尝试分开；普通拖动不应把其他窗口一起重排。
- 点击撤销；再手动改一个窗口后点击撤销：后者应跳过已改窗口。
- 快速连续拖动两次、跨屏、拖动时改变 DPI／工作区：不得执行过期的松手辅助。
- 只运行记录器，拖动和缩放几个普通窗口：出现几何 JSONL；关闭面板后托盘继续；暂停后不新增；退出后不再监听。
- 同时运行两个程序：整理与可逆填充还原不应被当作用户偏好；连续修正保留为带状态的观察。
- 导出 ZIP 检查无标题、进程名、句柄、截图和鼠标轨迹；清空后主程序其他设置仍在。
- 混合 DPI、多显示器负坐标、管理员窗口、自绘标题栏、极小工作区和 Win+方向键分别测试；不能把“监听不到”误报为学到了习惯。

CI 可证明编译与回归场景通过，不能证明以上真实桌面体验已经全部验证。
