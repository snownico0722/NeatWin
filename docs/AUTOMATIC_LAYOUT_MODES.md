# 四档自动整理与内置记录器

主页面顶部直接平铺四个选项，不使用下拉菜单。此前将“完整平铺”理解为第五种窗口布局算法是误解；正常界面和托盘不再提供这个操作。

| 档位 | 触发 | 操作 |
|---|---|---|
| 自动关 | 不自动触发 | 仍可手点整理或按快捷键 |
| 轻度辅助 | 拖动、缩放结束 | 原单窗口 FollowHand |
| 完整辅助 | 拖动、缩放结束 | 完整 Smart，和手点共用评分、候选、区域保护和执行链路 |
| 自动完整辅助 | 外部窗口开关、显隐、最小化恢复、前后台、层级和几何变化 | 完整 Smart；过滤自身变化 |

旧数值4迁移到自动完整辅助；原自动关/轻度设置不被擅自升级。切换到第四档整理一次，启动恢复只建立基线。变化安静450ms后合并处理，自动调用至少间隔1秒，拖动过程中不介入。上述时间是工程参数，不是人因实验结论。

自身位置、层级、落点取整、撤销由目标和操作标记过滤；冷却期间其他窗口的变化仍排队。撤销后不立即排回，下一次真实外部变化才重新判断。只有第四档安装广域窗口监听，前三档不持续轮询整个桌面。

## 整理强度与层级分开

扩大几何调整的尺寸候选范围，保留有界候选补全，降低有收益的重排阻力。但可见性、可操作区域、重要边缘和明确负面反馈不被同比放松。明确的暂存任务保持更保守的适应成本，不拟合每一个历史停手坐标。

被原来前窗遮挡的后窗不能仅凭几何评分跨越原遮挡者。点击 NeatWin 自己的界面时，外部窗口的 Foreground 标记可能全为 false，因此保护还直接核对原有几何遮挡关系，不依赖可见比例阈值。完全遮挡的窗口继续不进入 Smart 工作集。位置/尺寸改善不等于必须改变层级。

## 管理员权限

NeatWin.exe 通过 requireAdministrator 清单请求用户确认 UAC；不会绕过确认或修改系统 UAC 策略。支持同会话、同桌面管理员级普通窗口，仍保留最大化、固定尺寸、置顶、对话框及原生状态核验。管理员权限不等于能控制安全桌面、SYSTEM 或受保护系统窗口。

## 记录器

主程序内置 RecorderSession，在“记录器”页签显示状态、计数、暂停/继续、导出、打开目录与清空。观察和整理诊断共用会话及匿名窗口编号。暂停同时停止新增观察与计划日志，不停止运行时落点核验；清空使旧待写结果失效。

不记录标题、应用名、原始进程号/句柄、按键、截图或鼠标轨迹，不联网。已有几何记录本身仍属于个人数据。独立 Recorder 仅为兼容保留，启动新版前退出旧实例，以免记录锁被旧进程占用。

## 验证

独立CI负责回归和构建，Desktop smoke负责真实窗口事件、管理员目标、顶部四档控件、内置记录器和暂停/清空。PR不触发Release，合并并通过主线CI后才发正式版。压力测试和隔离桌面测试不是全部第三方应用的长期体验验收。
