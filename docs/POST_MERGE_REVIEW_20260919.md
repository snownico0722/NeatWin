## 运行与维护优化

候选成本只计算一次，诊断复用同一分项结果；操作前可见性按工作组缓存，不为每个候选反复计算。性能验证应使用相同生产核心回放输入、重复交替测量，并核对输出一致性，不能拿速度变化冒充意图理解改善。

关闭随手辅助时，不安装全局低级鼠标钩子，也不运行 120 ms 注意力和 25 ms 拖动指针计时器；保留窗口移动生命周期观察，主动整理仍能获得近期几何手势。开关重复开启不重复安装，关闭后释放。并未声称所有 Windows 观察都停止，独立记录器也不受此开关控制。

两个工作流补入 main 的 push 触发，避免只在 agent 分支与 PR 验证而遗漏合并后主线。此修改不增加写权限或跳过任何测试。

新增测试覆盖横纵视角、坐标原点平移、整组/部分/跳过撤销、纯层级撤销、填满开关与入口保护、随手辅助指针追踪生命周期，以及后处理的跨组计划碰撞。最终测试数量、提交、程序制品与离线计时以 PR 实际核对结果为准。
