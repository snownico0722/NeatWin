# 人因任务模型：关联稳定性、逻辑尺寸与区域保护

基线是 main `014b9888ba9412eb1f125b11765479df5f5447bb`。本轮改善实现机制，不以历史落点作标准答案，也不重训个人权重。暂存、共同观看、参考信息尺度与主动整理/随手辅助的区别保持不变。

## 改动

### 关联证据不再等同于搜索半径

旧实现超过半径就把两个窗口彻底分成不同组，明确提供的任务关系也会被提前丢弃。现在明确的同屏任务关系优先；自动关联同时考虑正交方向重合和距离，搜索半径外有平滑衰减带。原来可接纳的距离内保持完整支持，再在外侧 35% 范围内降低证据。距离以 DIP 计算，跨显示器或不同工作区不因提示而强行组合。

这些带宽是工程定义，不是心理概率或从用户坐标拟合的最佳值。有限候选的最优方案仍可能切换，因此不承诺任意微小扰动都得到相同结果。回归覆盖旧边界两侧、连续扫距、等价 DPI 与跨屏限制。

### 局部候选改为精确约束平移

旧的逐边松弛候选可能产生尺寸变化和中间解。仅把它换算到 DIP，仍会使候选在临界值附近不稳定。现在复用仓库中已经保留的 `ComfortSmartTidySolver`，在逻辑坐标中生成精确的局部平移候选，再换回当前窗口的物理坐标增量。

**它只是候选，不是替换整套 Smart 的只平移模式。** Task 模型仍比较缩放、叠边、叠放、贴边、普通层级和区域保护方案。Classic 与旧求解器代码不改。测试同时覆盖局部候选不隐式缩放，以及原有的无手动缩放历史也可产生有用缩放。

局部间距统一使用当前 IntentHint；同列分配采用不超预算的取整，避免各列四舍五入后多 1 像素，导致整套候选被淘汰。Smart 最小尺寸使用逻辑单位。DIP 与物理像素关系遵循微软说明：像素 = DIP × DPI / 96；DPI 并不提供真实观看距离。

### 保护具体区域，而不是只保护总面积

新增窗口相对坐标的 `TaskContentRegion`，可声明所需可见比例。已经达不到目标时，不再增加遮挡，允许逐步改善；不是把无法达到的完整可见率变成绝对门槛。

`ProtectPeriphery` 现在分别检查左、右、上、下四个区域，而不是仅比较整窗面积。候选按遮挡并集、实际目标位置和相对层级计算，屏外部分也算损失。没有移动的邻窗和视频后处理同样检查，防止移动另一个窗口绕过保护。允许 0.5 个百分点的栅格误差，不能拿它当可交易的权重。

托盘人因偏好增加“保护四侧边缘”，**默认关闭**，不改变本人允许正常叠放和少量外侧出屏的默认偏好。启用后四侧各 12% 的几何带被保护，同时禁用出屏。单个自定义区域通过上下文 API 提供，尚无逐窗口画区域的界面。

这不是自动识别字幕、导航栏、菜单或游戏 HUD。区域随窗口几何缩放，无法保证应用重新排版后真实内容仍位于同一处。需要真实语义时应由可靠适配器提供区域，不能把中央/边缘几何先验冒充识别结果。

### 有界的候选补全

选出初步有收益方案后，最多再生成两轮候选，始终用**原始任务证据、原始信息尺度、原始移动起点和安全约束**评分，最后只执行一次。不会把软件自己的中间结果作为用户偏好，也不在桌面上反复移动窗口。

诊断记录候选的 Generation（0–2）。这提高计算量，但可以减少部分“再次点击才继续整理”。它不是求解器天然幂等的证明；没有收益或超出安全约束时仍保留初始方案。

## 验证方法

先提交四项合成行为回归，确认旧实现 153 项通过、新增四项失败；修复不改它们的预期。再增加扫距、DIP、区域并集、屏外损失、固定邻窗、层级保护、配置兼容和候选成本回归。

旧记录仅在本地用于同输入的前后检查。既有 20,291 个变体冻结不变；不是 20,291 个独立真实任务，也不是未参与设计的数据留出集。分析使用独立区域计算，模型总分降低不作为人因成功标签。

还对局部松弛/精确平移、开启/关闭候选补全做消融。初次直接扩大搜索出现了额外跳变，没有把运行成功包装成全部通过；根据机制将局部候选改为精确约束，同时保留整体任务模型可缩放能力。实际 CI、同输入结果、计算开销和残留问题见 PR 最新验证记录。

`tools/NeatWin.Validation` 为读文件的离线适配器，不移动原生窗口、不联网、不上传数据。其输入、结果及几何时间信息都是用户数据，不能提交到公开仓库。CI 只使用合成示例构建适配器。所有日志回放仍不能替代本人 Windows 桌面的内容可用性和补调负担验收。

## 依据和边界

计算理性支持把手动操作成本与结果偏好分开，不提供本软件的数值系数：
https://research.aalto.fi/en/publications/computational-rationality-as-a-theory-of-interaction/

Windows 的 DIP/像素换算：
https://learn.microsoft.com/en-us/windows/win32/learnwin32/dpi-and-device-independent-pixels

本轮没有新增人格分类、眼动推断、自动应用语义识别或必须手动选择的工作模式。更高的可见比例、更多的改动或更接近历史坐标，都不能单独证明结果更好。
