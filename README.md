# NeatWin · 人因任务排布 v3

Windows 浮动窗口整理工具与独立习惯记录器。把粗摆当作意图草稿，而不是标准答案：替你承担继续整理的成本，不把“懒得继续调整”固化成布局规则。

## 使用

发布包中的 `NeatWin.exe` 是主程序，`NeatWin.Recorder.exe` 是只观察、不移动窗口的记录器。两者都是自带 .NET 运行时的 Windows x64 程序。升级前从托盘退出旧程序，再替换两个 EXE；保留在同一目录。无需删除已有记录。

主窗口标题含“人因任务排布 v3”；记录器继续使用兼容 v2 的记录格式。使用 Smart／均衡并主动点击整理即可，无需开启随手辅助，也无需刻意训练。

托盘新增“人因排布偏好”：允许或关闭有收益的缩放、小幅外侧出屏；调整参考信息尺度；可选输入当前工作区物理宽度与观看距离。不需要每次选择工作模式。未提供物理参数时不会猜测人眼视场角。

## 怎样做出决定

Smart 对同屏局部工作组比较共同观看、暂存叠放及同列关系。输入焦点不等于观看需求；后台播放器也可能需要持续可见。相同几何可能有不同用途，自动判断会保留不确定性，不声称识别了所有应用语义。

比较方案包含局部微调、并排、叠边、叠放、普通窗口层级、新的缩放／贴边／外侧空间交换／同列成组重排。尺寸可以改善，但没有无限铺满屏幕的奖励。保持 A 左、B/C 右侧同列等关系，而不是机械地把每个窗口分配到独立网格。

少量水平出屏默认开启，预算为 24 DIP 且不超过窗口宽度 3.5%，可关闭或调整。只考虑已知物理屏幕的外侧边缘，不越入相邻显示器、不侵占侧边任务栏、不上下出屏。屏外像素计入信息损失，不能刷高可见面积。边缘可能包含重要内容；几何中心只是代理，不能保证识别字幕、菜单或游戏 HUD。

相对层级不设置永久置顶、不主动抢焦点、不持续抢回层级。只调整安全的普通窗口工作组；无关窗口、对话框、永久置顶及身份／几何变化仍会限制执行。明确撤销包含几何与层级，已变化的相关组不会半套恢复。

程序区分候选、请求、实际落点及后续介入。明确撤销留下会话内局部负面反馈；普通手动后续可能表示换任务，不直接算否定；没有再修改不等于满意。只有实际核验匹配的近期结果才用于防重复漂移。

Classic 与小范围随手辅助保留。Smart 旧的强制几何填充不再覆盖任务目标；可选视频黑边功能仍作为内容提示和受任务目标约束的后处理。新版不是已验证的读心或眼动系统。

## 研究与用户画像

完整说明见 [人因任务模型 v3](docs/HUMAN_FACTORS_V3.md)：计算理性、混合主动交互、窗口管理实践、视觉注意、接近兼容性、空间任务管理、平铺／重叠对照和多窗口组操作的原始来源；逐项区分论文结论、本人明确偏好、工程初值与尚未验证的假设。

没有从历史“不缩放”频率拟合缩放厌恶，也没有把手动横移／纵移比例变成自动改动容忍度。旧数据不提供内容、真实眼动或满意标签，因此不报告虚构的意图准确率。

## 记录器与隐私

记录器可独立运行；关闭面板后在托盘继续观察，退出用托盘菜单。开机启动默认关闭。更换程序目录后应重新关闭、开启登录启动更新路径。

本地目录：`%LOCALAPPDATA%\NeatWin\Recorder`。

| 文件 | 内容 |
| --- | --- |
| `adjustments-*.jsonl` | 手势前后和短期确认的几何、层级及邻居上下文 |
| `workspace-*.jsonl` | 合并后的前台、层级、几何状态变化 |
| `plans-*.jsonl` | 候选、任务解释、成本分项、拒绝理由、请求与实际结果 |
| `intent-reference.json` | 去重、衰减和限幅的弱参考 |

不保存标题、应用名、进程号、原始句柄、按键、截图或鼠标轨迹；没有自动上传。匿名编号只用于会话内对应，几何和时间仍是个人数据，不要直接提交到公开仓库。原始日志合计限制为 32 文件／32 MB／30 天，可能因容量更早淘汰。

暂停只停止记录器观察；主程序仍可在主动整理时写诊断。完全停止新增数据须退出两者。“使用记录器的弱参考”只控制读取，不控制记录。明确偏好单独保存在 `%LOCALAPPDATA%\NeatWin\human-factors.json`，不包含窗口身份或原始日志。

## 构建与验证

Windows 10 2004 或更新版本／Windows 11，.NET 8 SDK。`global.json` 固定 .NET 8 系列。

```powershell
dotnet test tests/NeatWin.Tests/NeatWin.Tests.csproj -c Release
dotnet build src/NeatWin.Recorder/NeatWin.Recorder.csproj -c Release

dotnet publish src/NeatWin/NeatWin.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/win-x64
dotnet publish src/NeatWin.Recorder/NeatWin.Recorder.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o artifacts/win-x64
```

CI 执行测试、主程序／记录器构建与发布、启动检查，保存 TRX、源码快照和程序包。Desktop smoke 单独检查原生移动生命周期、普通层级调整和恢复。以相应提交的实际结果为准，不把测试存在当成已经通过。

`tools/NeatWin.Replay` 直接使用生产 Core 做离线几何回放。旧日志只能构造假设场景，不是现场重建或真人满意率。任务可用性、补调负担和重要信息误遮挡仍需实际桌面验收。
